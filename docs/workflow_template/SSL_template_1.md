# 만료 SSL 인증서 추출 및 갱신
- 설명 
  - 선정된 대상 플랫폼의 서비스에서 운용되는 SSL 인증서를 추출하여 만료가 도래하는 서비스를 확인하고 갱신이 필요한 서비스의 인증서를 요약하여 보고서를 작성
  - 승인자의 검토 후 인증서 갱신 수행

# 단계
1. 만료 SSL 인증서 추출한다. dprv-k8s 클러스터의 ingress 또는 route 에서 SSL 인증서 정보를 찾는다. 인증서를 파일로 저장한다.
2. 인증서 파일이 없는 경우 종료한다.
3. 추출한 인증서 파일의 만료일자를 확인하고 이를 보고서로 리포팅한다.
