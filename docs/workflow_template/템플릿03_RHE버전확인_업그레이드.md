# 설명
ansible 에이전트를 사용하여 리눅스 서버(RHEL) OS 버전을 확인하고 보고서를 작성한다. 스크립트는 ansible 을 사용하여 작성한다.

# 단계
1. {host_inventory} 호스트의 다음 정보를 추출하고 보고서를 작성한다.
  - OS 버전
  - kernel 버전
  - cpu/mem 정보
2. 이전 작업 결과를 전달받아서 EOSL 대상 버전을 필터링하여 전체 대비 업그레이드가 필요한 호스트 보고서를 덧붙여 작성한다. EOSL기준은 RHEL 기준으로 일반적인 EOSL 정보를 활용한다. 이 작업은 helpdesk 에이전트를 사용한다.
3. 결재자 {userid} 의 승인 후 작업을 종료한다.
