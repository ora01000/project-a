# 이름
OKD 클러스터 일일 보고서 생성

# 설명
OKD {cluster_name} 클러스터 일일 점검 리포트를 생성한다. {cluster_name}는 Kubernetes 에이전트를 사용하고 모든 스크립트는 자연어 프롬프트로 구성한다.

# 단계
1. {cluster_name} 클러스터의 전체 노드 목록과 상태를 추출, 리포트 출력
2. {cluster_name} 클러스터의 Pending CSR 유무를 체크, 이전 작업 결과를 받아서 리포트에 추가
3. {cluster_name} 클러스터의 이벤트 조회, 특이사항이 있는지를 판단, 이전 작업 결과를 받아서 리포트에 추가
4. {cluster_name} 클러스터의 Cluster Operator 상태를 체크, 이전 작업 결과를 받아서 리포트에 추가
5. {cluster_name} 클러스터의 API Service 상태 체크, 이전 작업 결과를 받아서 리포트에 추가
6. 승인자 {userid} 의 승인 후 종료
