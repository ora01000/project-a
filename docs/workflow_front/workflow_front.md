# 작업 워크플로우

작업 워크플로우는 에이전트 작업을 순차적으로 구성하고, 관리자 승인 절차를 포함해 작업 계획을 만들고 수행·이력을 관리할 수 있습니다.

왼쪽 목록에서 워크플로우를 선택해 편집하거나, **새로운 작업 워크플로우**로 생성을 시작하세요.

## 주요 기능

- ![생성·편집](/workflow-icons/edit.svg) **생성·편집**: 이름·설명·다이어그램·스케줄을 구성한 뒤 저장합니다. 소유자만 수정·삭제할 수 있습니다.
- ![실행](/workflow-icons/run.svg) **실행**: 목록의 실행 버튼으로 즉시 수행하거나, 워크플로우 스케줄(당일 1회·매일·평일·매주·매월)로 자동 실행합니다.
- ![작업노드](/workflow-icons/work-node.svg) **작업노드**: kubectl / ansible / cli / prompt 등 에이전트 작업을 연결하고, 스크립트 검증·파일 첨부·이전 결과 참조·결과 메일을 설정합니다.
- ![승인](/workflow-icons/approve.svg) **승인(HITL)**: 승인자 노드에서 결재 대기 → 승인·반려(필요 시 파일 업로드) 후 다음 단계로 진행합니다.
- ![이력·결과](/workflow-icons/history.svg) **이력·결과**: 하단 탭에서 실행 이력, 노드별 작업 결과, 에이전트 로그를 확인합니다.

## 다이어그램 별 기능

- ![노드](/workflow-icons/nodes.svg) **노드**: 시작 · 작업노드 · 승인자 · 종료. 작업노드에 결과 메일 설정 시 메일 배지가 표시됩니다.
- ![연결](/workflow-icons/connect.svg) **연결**: `+` 메뉴로 다음 작업노드, 승인자, 실패 시 작업노드(또는 종료)를 추가합니다. 성공 흐름은 가로, 실패·메일은 아래 분기로 이어집니다.
- ![실패 분기](/workflow-icons/fail-branch.svg) **실패 분기**: 작업 실패 시 별도 작업노드 또는 종료로 분기합니다.
- ![실행 제어](/workflow-icons/stop.svg) **실행 제어**: 실행 중에는 편집이 잠기고, 진행 중인 작업노드를 중지할 수 있습니다. 노드 예약 시각까지는 예약 대기 상태로 표시됩니다.
- ![AI 생성](/workflow-icons/ai.svg) **AI 생성**: 새 워크플로우 생성 화면에서 프롬프트(또는 템플릿)로 다이어그램을 자동 구성할 수 있습니다.

## 배포와 복제

- ![소유권](/workflow-icons/owner.svg) **소유권**: 생성한 사용자가 소유자이며, 소유자만 편집·저장·삭제·배포 설정을 변경합니다.
- ![배포](/workflow-icons/distribute.svg) **배포**: 배포하면 다른 사용자가 목록에서 조회·실행·복제할 수 있습니다. 편집은 소유자만 가능합니다.
- ![복제](/workflow-icons/clone.svg) **복제**: 선택한 워크플로우와 하위 작업노드를 새 UUID로 복사합니다. 복제본의 소유자는 복제한 사용자이며, 배포 상태는 해제됩니다.
- ![목록 표시](/workflow-icons/list.svg) **목록 표시**: 본인이 소유하거나 배포된 워크플로우만 보입니다.

## 생성 템플릿

- ![템플릿](/workflow-icons/template.svg) 생성 화면의 양식에서 `docs/workflow_template`에 있는 템플릿(`.md`)을 선택할 수 있습니다.
- ![변수](/workflow-icons/variable.svg) 템플릿에는 `{변수}` 자리 표시자가 있어, 입력값을 치환한 뒤 AI 다이어그램 생성에 사용합니다.
- ![빠른 시작](/workflow-icons/quickstart.svg) 일일점검, SSL 인증서 점검, RHE 버전 확인, K8S deploy 생성, K8S Route 인증서 적용 등 준비된 양식으로 빠르게 시작할 수 있습니다.
- ![세션](/workflow-icons/session.svg) 템플릿 원본 파일은 서버에만 보관되며, 화면에서 수정한 내용은 해당 생성 세션에만 반영됩니다.
